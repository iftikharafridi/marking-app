Marking & Feedback App

Rubric-based marking, feedback generation & academic workflow management

Developed by Iftikhar Afridi · Ulster University

🔒
Privacy Notice — All processing happens locally in your browser. No student data, marks, or feedback are uploaded to any external server. The app works fully offline after loading.
1
Select Module & Load Rubric Required

Open ⚙ Setup in the sidebar. Choose your university, programme, module and assessment from the dropdowns to load a built-in rubric automatically. Alternatively, paste your own rubric markdown or upload a .md file and click Load Rubric.

📄 Show sample rubric format 
---
module_code: COM101
module_title: Introduction to Computing
tutor_name: Dr. Smith
semester: S1 2024-25
partner: Ulster University
---

# Criterion 1: Analysis [30]
## Marks: 25 - 30 (Distinction)
- Comprehensive and insightful analysis
- All key concepts addressed with depth

## Marks: 19 - 24 (Commendation)
- Clear analysis with minor gaps
- Most concepts addressed

## Marks: 13 - 18 (Pass)
- Basic analysis present
- Some concepts missing

## Marks: 0 - 12 (Fail)
- Limited or superficial analysis

# Criterion 2: Implementation [40]
## Marks: 34 - 40 (Distinction)
- Fully working solution
- Clean, well-structured code

## Marks: 27 - 33 (Commendation)
- Mostly working solution
- Minor issues present

## Marks: 20 - 26 (Pass)
- Partial implementation
- Significant issues present

## Marks: 0 - 19 (Fail)
- Not working or missing
2
Enter Your Name Required

In ⚙ Setup, type your name in the First Marker Name field. This appears in every piece of generated feedback — it is intentionally blank so each marker must enter their own name.

3
Import Students or Restore a Workbook Optional

Import Student List adds names to the currently loaded module. Restore Marking Workbook reopens a workbook previously exported by this app and automatically restores the partner, programme, module, rubric and marks. Do not restore a marking workbook onto a different rubric — the app will load the saved rubric first.

4
Mark Each Student

Select a student from the sidebar dropdown or use ◀ Prev / Next ▶. In the 📝 Mark tab, tick feedback points for each criterion and add per-criterion comments. Use 💬 Overall Comments for general feedback. Set the student's Status (e.g. Non-Submission, EC Approved, Resit, Withdrawn) using the dropdown in the sidebar.

5
Export Feedback

At the bottom of the Mark tab: 📋 Copy text for plain feedback · 🎓 Blackboard for formatted HTML · 📄 Word doc to download .docx · 🔧 Moodle XML for Moodle import.

6
Save Your Session

Click 💾 Save to Excel at any time. Creates a file with two sheets: Marks (readable summary with per-criterion columns) and Full Data (used to restore the session by re-importing). A third Tasks sheet saves all module tasks.

7
Track Issues & Tasks

Use the 🚩 Issues tab to manage two separate lists: Student Issues (per-student flags such as academic misconduct, EC cases, viva required) and Module Tasks (operational to-dos such as moderation meetings, uploading marks, contacting the module leader). Tasks support priority, deadline and status tracking.
